Häufig gestellte Fragen (FAQ)

Alles Wichtige über Malvo Cord, den Plugin Store und Sicherheit.

Ist Malvo Cord wirklich 100% kostenlos und Open Source?

Ja! Sowohl die Discord Bridge als auch der gesamte Community Plugin Store sind komplett kostenlos und unter der GPL-3.0 lizenziert. Es gibt weder Abos noch kostenpflichtige Plugins.

Wie funktioniert der Plugin Store?

Der Store holt geprüfte Plugins direkt aus dem offiziellen Malvo Cord Community-Repository. Mit einem Klick auf "Installieren" lädt dein Malvo Client die Erweiterung herunter und aktiviert sie sofort ohne Neustart.

Wird Discord Nitro benötigt?

Nein. Alle Kernfunktionen – Chatten, Kontakte, Media-Sync und Rich Presence – funktionieren uneingeschränkt mit einem ganz normalen, kostenlosen Discord-Account.

Kann ich eigene Plugins programmieren?

Absolut! Über das Malvo Plugin SDK kannst du mit einfachem TypeScript/JavaScript und CSS eigene Plugins bauen und per Pull Request auf GitHub einreichen, damit sie im Store erscheinen.
